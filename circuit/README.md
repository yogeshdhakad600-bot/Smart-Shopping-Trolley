# Circuit Diagram

Place the actual circuit drawing in this folder, for example:

- `wiring_diagram.png`
- `wiring_diagram.pdf`
- The editable source file from your circuit-design tool, if available

The final diagram should show the ESP8266 NodeMCU, IR sensor, three ultrasonic sensors, L298N motor driver, DC motors, battery/regulator, common ground, and emergency-stop motor-power cut-off.

Do not label the RFID reader or mobile app as implemented until they have been built and tested. Refer to [`../hardware/wiring_guide.md`](../hardware/wiring_guide.md) for provisional wiring notes.
